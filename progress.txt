## Codebase Patterns

- This project is a premium single-page portfolio built with Next.js and should remain primarily single-page unless a future PRD explicitly changes that.
- The hero section is currently considered a protected strength of the site and should not be changed unless a story explicitly targets hero refinement.
- Lower-page redesigns must preserve compatibility with the hero in tone, spacing quality, typography feel, and visual sophistication.
- Prefer small, local, story-scoped edits over broad rewrites.
- Preserve the core dark / wine / cream visual identity across redesign work.
- Avoid generic template-style section composition, especially below the hero.
- Avoid placeholder-feeling production UI copy.
- Content changes must not invent fake client work, fake metrics, fake testimonials, or fake outcomes.
- UI improvements should prefer fewer stronger blocks rather than many weak or repetitive sections.
- Any reusable visual or structural discovery should be appended here only if it will help future iterations.
