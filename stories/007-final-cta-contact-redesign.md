# Story 007 - Final CTA / Contact Redesign

## Status
`done`

## Objective
Redesign the final CTA/contact area so it feels intentional, calm, premium, and ready for real professional use.

## Context
The final section of a portfolio often determines whether the site ends with confidence or fades out like a placeholder. The current contact surface should feel like a deliberate closing argument, not an afterthought.

## In Scope
- redesign the final CTA/contact section
- improve layout and visual tone
- improve copy framing if needed
- improve the clarity of the contact path
- make the closing section feel consistent with the premium identity
- improve mobile behavior
- simplify awkward layout choices if necessary

## Out of Scope
- hero redesign
- services redesign
- selected work redesign
- footer redesign beyond what is necessary for section coherence
- implementing a complex backend contact workflow unless explicitly required
- introducing aggressive sales copy

## Acceptance Criteria
- the final section feels intentional and premium
- the CTA language is clear and credible
- the section no longer feels placeholder-like
- the layout is coherent on desktop and mobile
- the section closes the page gracefully
- the contact path is obvious without feeling pushy

## Likely Files
- contact/final CTA section component
- related content file
- form/contact UI pieces if present
- surrounding section wrapper if local adjustments are necessary

## Dependencies
- `PRD.md`
- `brand.md`
- `decisions.md`
- Story 002
- Story 003

## Validation
- run relevant lint/typecheck/build commands if code is changed
- manually verify desktop layout
- manually verify mobile layout
- confirm CTA clarity
- confirm no awkward two-column contact composition remains unless clearly justified

## Implementation Notes
- keep the tone calm and direct
- avoid generic “let’s build something amazing” filler
- avoid overbuilt forms if a simpler contact surface is stronger
- treat this as a real conversion surface
